Effects Documentation

This directory contains detailed documentation for all NUX MG30 effects organized by category.

Categories​

🎵 WAH - Wah-Wah Effects​

  • Clyde - Fulltone Clyde Deluxe emulation
  • Cry BB - Classic Cry Baby wah
  • V847 - Vox V847 wah
  • Horse Wah - Experimental wah
  • Octave-Shift - Octave + wah combination

🔧 CMP - Compression Effects​

  • Rose Comp - Ross Compressor emulation
  • K Comp - Keeley Compressor emulation
  • Studio Comp - Professional studio compression

🚪 GATE - Noise Gate​

  • Noise Reduction - Intelligent noise suppression

🎸 EFX - Distortion & Boost Effects​

  • Dist+ - MXR Distortion+ style
  • RC Boost - Clean booster RC style
  • AC Boost - Xotic AC Booster style
  • Dist One - Boss DS-1 distortion
  • T Scream - Tube Screamer overdrive
  • Blues Drv - Boss Blues Driver style
  • Morning Drv - JHS Morning Glory style
  • EAT - ProCo RAT distortion
  • Red Dirt - Keeley Red Dirt Overdrive
  • Crunch - MI Audio Crunch Box
  • Muff Fuzz - Big Muff fuzz
  • Katana Boost - Boss Katana Clean boost
  • Red Fuzz - Fuzz Face style
  • Touch Wah - Touch-sensitive wah
  • ST Singer - NUX Steel Singer
  • Klon - Centaur-style overdrive
  • Legend Drive - Legendary overdrive
  • Mood - Atmospheric effect

⚡ EQ - Equalization Effects​

  • 6-Band - Parametric 6-band EQ
  • Align - Corrective EQ for tonal alignment
  • 10-Band - Graphic 10-band EQ
  • Para - Full parametric EQ

🔄 S/R - Send & Return Loop​

  • Send/Return - External effects loop
    • Send: Signal level control (-15dB to +15dB)
    • Return: Return signal level (-15dB to +15dB)
    • Branch/Serial: Routing selector (parallel/series)
    • Chain Position: Between EQ and RVB

🌊 MOD - Modulation Effects​

  • CE-1 - Boss CE-1 chorus
  • CE-2 - Boss CE-2 chorus
  • ST.Chorus - Stereo chorus Roland JV-1000 style
  • Vibrator - Vox Repeat Percussion
  • Detune - Subtle pitch shifting
  • Flanger - Classic flanger effect
  • Phase 90 - MXR Phase 90
  • Phase 100 - MXR Phase 100
  • S.C.F. - Stone Chorus Flanger
  • U-Vibe - Univibe emulation
  • Tremolo - Fender tremolo
  • Rotary Speaker - Leslie rotating speaker
  • Harmonist - Intelligent harmonizer
  • SPF-1 - Special phase filter

⏰ DLY - Delay Effects​

  • Analog Delay - Boss DM-2 style
  • Digital Delay - Boss DD-3 style
  • Modulation - Chorus-modulated delay
  • Tape Echo - Maestro Echoplex emulation
  • Reverse - Reverse delay playback
  • Pan Delay - Ping-pong stereo delay
  • DuoTime - Dual delay with different times
  • Phi Delay - Specialized delay effect

🌌 RVB - Reverb Effects​

  • Room - Small room simulation
  • Hall - Concert hall simulation
  • Plate - Classic plate reverb
  • Spring - Spring reverb amp-style
  • Shimmer - Reverb with upper octaves
  • Damp - Damped reverb with frequency dampening

🎛️ GLOBAL - Global Controls​

  • Patch Level - Overall preset level control
    • MIN: Range 0-50 (minimum level control)
    • MAX: Range 51-100 (maximum level control)
    • Position: Final in effect chain, after RVB
