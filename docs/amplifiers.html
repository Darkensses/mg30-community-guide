Amplifier Simulations

This directory contains detailed documentation for all NUX MG30 amplifier simulations organized by type and era.

  • Jazz Clean - Roland JC-120 stereo clean
  • Deluxe RVB - Fender Deluxe Reverb classic
  • Twin RVB - Fender Twin Reverb power
  • Hiwire - Hiwatt Custom 100 British clean
  • F Princeton - Fender Princeton Reverb vintage

🔥 Vintage Crunch - Classic Overdriven Tones​

  • Tweedy - Fender Tweed character
  • Bassmate - Fender Bassman foundation
  • Class A15 - Vox AC15 chime
  • Class A30 - Vox AC30 British classic
  • Plexi 45 - Marshall JTM45 vintage

⚡ British Rock - Marshall & British Tones​

  • Plexi 100 - Marshall Super Lead 100 (Plexi)
  • Brit 800 - Marshall JCM800 crunch
  • 1987 X 50 - Marshall 1987X (Plexi 50W)
  • Brit Blues - Marshall Bluesbreaker
  • JCM900 - Marshall JCM900 modern
  • Brit 2000 - Marshall JCM2000 DSL

🎸 High-Gain Modern - Metal & Modern Rock​

  • SLO 100 - Soldano SLO-100 American high-gain
  • Dual Rect - Mesa Boogie Dual Rectifier
  • Die VH4 - Diezel VH4 German precision
  • Uber - Bogner Uberschall German high-gain
  • Fireman - Friedman BE-100 HBE boutique

🎯 Boutique & Specialty - Unique Character Amps​

  • Budda - Budda Superdrive boutique
  • Mr.Z 38 - Dr. Z MAZ 38 boutique clean/crunch
  • Match - Matchless DC-30 British boutique
  • L Star - Laney Lionheart British character
  • Vibro King - Fender Vibro King with vibrato

🎵 Bass Amplifiers - Low-End Foundation​

  • AGL - Aguilar Tone Hammer modern preamp

  • MLD - Gallien-Krueger 800RB modern

  • Optima Air - Fishman Aura/Acoustic simulation

Amplifier Characteristics​

Clean Amplifiers​

Perfect for jazz, country, funk, and as a foundation for pedal-driven tones.

Vintage Crunch​

Classic rock, blues, and vintage sounds with natural tube saturation.

British Rock​

The Marshall sound - from classic rock to hard rock crunch.

High-Gain Modern​

Metal, hardcore, and modern rock with tight, aggressive distortion.

Boutique​

Unique character amplifiers with specialized voicing and response.

Bass Amplifiers​

Complete bass amplifier simulations from vintage to modern.

Documentation Format​

Each amplifier includes:

  • Description - Tone character and real-world inspiration
  • Parameters - All available controls (gain, master, EQ, etc.)
  • Sweet Spots - Recommended settings for different styles
  • Compatible Effects - Which effects work best with each amp
  • Famous Users - Artists known for using the real amplifier

Tone Matching Guide​

For Blues & Classic Rock​

  • Clean: Jazz Clean, Deluxe RVB, Twin RVB
  • Crunch: Plexi 45, Class A30, Brit Blues

For Modern Rock & Metal​

  • High-Gain: SLO 100, Dual Rect, Die VH4
  • Tight Metal: Uber, Fireman

For Country & Clean Tones​

  • Crystal Clean: Jazz Clean, Twin RVB
  • Edge of Breakup: Deluxe RVB, F Princeton

For Bass Players​

  • Classic: Bassguy (Ampeg SVT)
  • Modern: AGL, MLD, Dglass
  • Versatile: Starlift, Vivo
